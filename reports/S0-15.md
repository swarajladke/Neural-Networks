## 7. Mathematical audit of slot consolidation

### 7.1 Rank-1 Geometric Constraint
- Governing Equation: Delta = u r^T  ==>  k_g Delta = (k_g u) r^T
- Geometric Reality: For any rank-1 update, all changes to collision-group keys lie along the identical output direction r. If two keys k1, k2 have cosine similarity >= 0.999, k1 u ~= k2 u, forcing realized updates v1 and v2 to shift by approximately the same vector r.

### 7.2 Feasibility Regimes
- Compatible Targets: Feasible: If different prompts with near-identical subject keys require compatible downstream directions, a shared v* can satisfy both.
- Contradictory Targets with Identical Prompt: Mathematically Infeasible: Two identical prompts with conflicting target tokens cannot be resolved by any rank-1 update or any single v*.
- Near-Parallel Keys with Orthogonal Residuals: Infeasible / Approximated: If desired residuals r_1, r_2 are orthogonal (<r_1, r_2> = 0), a single rank-1 direction r cannot satisfy both; error >= 1/sqrt(2) ||r_2||.
- Different Relation Contexts Sharing Subject: Conditional: Sharing subject key k across different relation contexts succeeds if layers 2-11 attention routing branches the prompt context tokens.

### 7.3 Unit Test Verification (Tests 3.49 - 3.53 in tests/test_metrics.py)
- Test 3.49: Identical keys with compatible targets confirmed feasible (max incompatibility < 1e-6).
- Test 3.50: Identical keys with contradictory targets reported infeasible (incompatibility > 1.0).
- Test 3.51: Near-parallel keys with orthogonal residuals detected as incompatible (incompatibility = 1.0).
